
# Data Analysis Suite

Программа для обработки и анализа табличных данных (Excel) с функциями нормализации, корреляционного и регрессионного анализа, описательной статистики и прогнозирования.

## ВАЖНО
Для работы требуется Python 3.10 и следующие библиотеки:
- pandas
- numpy
- scipy
- tksheet
- matplotlib
- seaborn
- openpyxl (для работы с Excel)
- модуль `statist`, `corel`, `regression`, `normalizer`, `forecast`, `excel_reader` (в составе поставки)
- tkinter (обычно уже есть в Python)

## Как запустить

1. Убедитесь, что все зависимости установлены (см. выше).
2. Поместите свой Excel-файл с данными в любую удобную папку.
3. Запустите программу командой:

bash
python main.py


## Основные функции

- **Открыть Excel** — загрузка файла Excel для анализа.
- **Нормализация** — преобразование данных к единообразному масштабу.
- **Корреляция** — расчет матрицы парных и частных корреляций, t-критериев, построение плеяд, множественная корреляция.
- - в **корреляциях** связи выделены цветом по правилу:
    – красный цвет – очень слабая связь;
    – оранжевый цвет – слабая связь;
    – фиолетовый цвет – средняя связь;
    – синий цвет – сильная связь;
    – зеленый цвет – очень сильная связь.
- **Регрессия** — расчет уравнения регрессии, анализ коэффициентов, текстовые отчеты, оценка адекватности, сравнительный анализ.
- **Прогнозирование** — расчет Y по введённым Х на базе построенной модели.
- **Статистика** — графики плотности, описательная статистика, статистические ряды, проверка на нормальность.

## Пример работы

1. Нажмите кнопку **"Открыть Excel"** и выберите файл с данными.
2. Проведите **нормализацию**, чтобы подготовить данные к анализу.
3. Используйте кнопки панели для расчета корреляций, регрессии, статистики, прогнозирования.
4. Справка (настоящий файл) всегда доступна по кнопке "Справка / Инструкция".

## Требования к данным

- Ваша таблица должна содержать числовые значения.
- Первая строка не должна содержать данные, а должна содержать заголовки к данным.
- Последний столбец должен содержать отклик Y, остальные — факторы X1, X2, ..., Xn.
- Рекомендуемый формат Excel: `.xlsx` или `.xls`.

## FAQ

- **В: Не запускается, возникают ошибки модулей tksheet или pandas.**
  - О: Установите их через pip:  
    `pip install tksheet pandas openpyxl matplotlib seaborn`

- **В: Анализ не работает, пишет "Нет данных".**
  - О: Сначала откройте файл Excel и выполните нормализацию.
